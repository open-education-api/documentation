# OEAPI specification

The Open Education API (OEAPI) specification defines a shared information
model and standardised endpoints for exchanging education data.

## API reference

Explore the endpoints, data models and operations defined in the
specification. Select the appropriate version for your implementation.

## Versions and releases

Find published releases and release candidates, including the
corresponding OpenAPI files in YAML and JSON format.

Use a published release for production implementations. Release
candidates are intended for review and testing and may still change.

## Implementing OEAPI

Use the specification as the contract between applications that provide
education data and applications that consume it. Agree on the version
to be implemented and consult the accompanying technical documentation
for implementation guidance.
